    Wallpaper sources

    Everything the slideshow can draw from. Switch a source off to skip it without losing it. Folders include sub-folders two levels deep.

    Online sources are opt-in. A catalogue is a small JSON list of https image addresses with optional title, author and licence. Only image files are downloaded and cached on this device; nothing about you is sent or tracked, and when offline the launcher quietly uses the bundled wallpapers. Changes to online sources apply when you save.
